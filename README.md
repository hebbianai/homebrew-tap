# Hebbian AI Homebrew tap

```sh
brew install --cask hebbianai/tap/catchtype
```

[Catchtype](https://catchtype.com/) fixes Korean typed in English mode and English typed in Korean mode as you type, and switches the input state for you. macOS 13 or later. Apple silicon and Intel.

The first time, open Catchtype and turn it on in System Settings > Privacy & Security > Accessibility. After that the app updates itself (`auto_updates`), so `brew upgrade` skips it unless you pass `--greedy`.

Problems: https://catchtype.com/en/feedback
